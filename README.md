# 588415 Node Page

Off-node reference site for AllStarLink node 588415, published with GitHub
Pages using Jekyll's `minima` theme. GitHub builds this automatically from
the Markdown files on push — there is no local build or deploy step.

## Structure

- `_config.yml` — site settings and theme
- `index.md` — home page, with the Online/Offline status indicator
- `about.md`, `changelog.md` — content pages, linked from the home page and the site nav
- `_includes/` — shared header, footer and status indicator, the same in every node repository

Pages setup: Settings → Pages, source "Deploy from a branch," branch `main`, folder `/ (root)`.
